# App Gestione Campionato Piccoli Amici 2017

App web per la gestione di partite, classifiche e tornei estivi.

## Caratteristiche principali
- **Dashboard:** Prossime partite e ultimi risultati con loghi e info campo.
- **Classifica Automatica:** Calcolo punti (3-1-0) basato sui risultati inseriti.
- **Area Allenatori:** Accesso protetto per gestione rosa e inserimento risultati.
- **Classifica Marcatori:** Conteggio gol individuale.
- **Sezione Tornei:** Gestione eventi extra e tornei estivi.

## Tech Stack (Previsto)
- Frontend: React + Tailwind CSS
- Database/Auth: Firebase
